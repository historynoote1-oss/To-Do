# تحديث صفحة مجالات الحياة (Life Areas) — ملفات جاهزة للنسخ

## الملفات في هذا الأرشيف

```
src/
├── styles.css                                  ← استبدل به ملف الأنماط بالكامل
├── components/common/
│   └── ColorPicker.tsx                         ← ملف جديد كليًا
└── pages/life-areas/
    ├── LifeAreasManager.tsx                    ← استبدال كامل للملف الحالي
    └── QuickCreateLifeArea.tsx                 ← استبدال كامل للملف الحالي
```

## طريقة التركيب

1. انسخ `src/components/common/ColorPicker.tsx` كملف جديد في مشروعك بنفس المسار
   (`frontend/src/components/common/ColorPicker.tsx`).
2. استبدل `frontend/src/pages/life-areas/LifeAreasManager.tsx` بالكامل بالملف الموجود هنا.
3. استبدل `frontend/src/pages/life-areas/QuickCreateLifeArea.tsx` بالكامل بالملف الموجود هنا.
4. استبدل `frontend/src/styles.css` بالكامل بالملف الموجود هنا (ملف الأنماط الوحيد
   في المشروع — تم التعديل عليه في نفس مكانه، وباقي كل الصفحات التانية زي ما هي
   من غير أي تغيير).

## ملحوظة مهمة

ملف `styles.css` هنا هو ملف الأنماط **الكامل** بتاع المشروع كله (مش ملف منفصل
لمجالات الحياة بس) — لأن المشروع الأصلي بيستخدم شيت واحد لكل الصفحات. التعديلات
الخاصة بمجالات الحياة (منتقي اللون، شكل الكارت المضغوط، لوحة التفاصيل...) محصورة
جوّاه ومحدّدة بتعليقات عربي توضح كل قسم.

كل الوظائف القديمة (تعديل، حذف بتأكيد، رفع صورة، مجالات فرعية غير محدودة، النقل
اليدوي بالأسهم) لسه موجودة زي ما هي — الإضافات فوقها بس (منتقي لون احترافي،
كارت مضغوط، سحب وإفلات للترتيب).
